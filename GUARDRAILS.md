# Guardrails

This repository is built to comply with **RFP Section 6.3 (Prohibited)**. Each
prohibited item is addressed explicitly below.

## No secrets or API keys committed to the repository

Credentials are read from the environment only (`os.environ`, loaded from a local
`.env` via `python-dotenv`). `.env` is listed in `.gitignore` and is not tracked.
The only committed configuration file is `.env.example`, which contains empty
placeholder values. No key, token, or secret is hardcoded anywhere in source.

## No real client names, phone numbers, or recordings from an actual HoldNote client

The only audio file in this repository is `samples/intake_sample.mp3`. It is a
**fictional** intake, written for this prototype, for an **invented** business:
"Bright Harbor Family Dental", owner "Priya", town "Meridian". None of these
refer to a real business or a real person.

- No real phone number appears anywhere in the repository. The sample script
  deliberately omits one ("our phone number is the same as it's always been"),
  which is also used to demonstrate the tool flagging missing information.
- No recording, transcript, script, or brief from an actual HoldNote client is
  included.
- The exact words in the audio are committed as plain text in
  `samples/intake_sample.txt`, with a header stating it is fictional.

## No cloned voices used without the speaker's explicit consent

No voice is cloned, sampled, or imitated. `samples/intake_sample.mp3` was
generated by a **built-in macOS system text-to-speech voice** ("Samantha") using
the `say` command, from the text in `samples/intake_sample.txt`:

```
say -v Samantha -f samples/intake_sample.txt -o /tmp/intake.aiff
ffmpeg -i /tmp/intake.aiff -ac 1 -ar 16000 -b:a 64k samples/intake_sample.mp3
```

No person's voice was recorded or used as a model. The tool itself does not
perform, request, or depend on voice cloning at any point in its flow.

## No copyrighted commercial audio (music, hold-music beds, unlicensed sound libraries)

There is no music, hold-music bed, jingle, stinger, or third-party
sound-library asset anywhere in this repository. No licensed, royalty-free, or
stock audio is used. The single audio file, `samples/intake_sample.mp3`, is
machine-generated text-to-speech and carries no third-party rights.

Speech-to-text is performed by the OpenAI API at runtime; no audio model,
dataset, or media library is bundled with or redistributed by this repository.

## Exactly one outcome (RFP Section 2)

This concept targets exactly one outcome for HoldNote: **reduced owner-time**.
It does not target increased revenue, and it does not try to do both. There is
no upsell, pricing, packaging, or lead-generation path in the tool. This is
declared in code as the `OUTCOME` constant in `main.py` and recorded in every
run's `out/brief.json` as `meta.target_outcome`.

## Scope note

This prototype does not generate spoken output. It transcribes a spoken intake
and produces a text brief for the studio owner to review. Any future
text-to-speech preview would use a clearly labelled synthetic voice with the
same guardrails above - never a client's or a third party's voice without
written consent.
