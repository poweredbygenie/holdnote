# samples/

## `intake_sample.mp3`

The default input for `python main.py`. A stand-in for a client's spoken intake.

### How it was made

The text in [`intake_sample.txt`](intake_sample.txt) was run through the built-in
macOS `say` command (system voice **"Samantha"**) and encoded to MP3 with
`ffmpeg`. It is 100% machine-generated text-to-speech.

### Rights and licensing — RFP Section 6.3

- **No copyrighted commercial audio is used.** There is no music, no hold-music
  bed, no jingle, and no sound library or stock / royalty-free audio — in this
  file or anywhere in this repository. No "sound libraries without rights" are
  used because no sound library is used at all.
- **No cloned voices.** No human voice is recorded, sampled, or cloned. The
  speaker is a synthetic operating-system text-to-speech voice.
- **No real client data.** The business ("Bright Harbor Family Dental"), person
